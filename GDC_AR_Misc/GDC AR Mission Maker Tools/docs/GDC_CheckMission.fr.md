# Vérification de mission (GDC Mission Maker Tools)

[English](GDC_CheckMission.md) | Français

Le plugin **Check Mission** vérifie le monde de mission ouvert et signale ce qui casserait une partie ou mérite un coup d'œil. Il lit le monde sans jamais le modifier.

## Utilisation

1. Ouvrez votre monde de mission.
2. Lancez **Plugins > GDC > Check Mission**, ou **Ctrl+Alt+C**.
3. Lisez le résumé, puis le détail dans la **Log Console**, filtrée sur `[GDC_CHECK]`.
4. Corrigez, puis relancez avec Ctrl+Alt+C ou le bouton **Check again**.

## Réglages

Dans **Plugins > Settings > Check Mission** :

| Réglage | Rôle |
|---|---|
| Blocs (Mission Structure, Resources And Addons…) | les blocs de contrôles à lancer ; un bloc décoché est indiqué comme ignoré, jamais comme réussi |
| Skeleton Config | le squelette de mission auquel le bloc 1 compare la mission : le même que dans [Create Mission Skeleton](GDC_MissionSkeleton.fr.md) |
| Show Info | affiche ou non les constats de niveau Info dans le rapport ; ils restent comptés dans le résultat |
| Language | langue des fenêtres et du rapport : anglais ou français |

## Lire le rapport

Chaque constat donne :

- sa **gravité** : **erreur** (casse la partie, à corriger), **avertissement** (peut être voulu, à vous de juger) ou **info** ;
- le numéro et le titre de la règle, avec son **origine** entre crochets : vanilla, GDC, ou un framework (TILW, RL pour Reforger Lobby) ;
- **Où** : le calque et l'entité. Cliquez sur le lien `@"ENTITY:…"` pour sélectionner l'entité dans le monde ;
- **Problème** et **Correction** ;
- **Fiche**, quand la règle en a une : l'adresse de sa page dans la base de connaissance, à copier dans le navigateur.

Les règles d'un framework ne tournent que si la mission l'utilise, c'est-à-dire si elle place au moins une de ses entités. L'en-tête du rapport indique les origines utilisées.

## Les contrôles

La base de connaissance explique les règles dont la raison n'est pas évidente : preuve, contournement, et à quel moment la règle pourra disparaître. Le titre de ces règles est un lien vers leur fiche.
