## What is it ?
Very simple mod with some compositions (very few at the moment), with Rpl component enabled or added so that these compositions can be used with dynamic spawn on the server side.

How to create compos : https://community.bohemia.net/wiki/Arma_Reforger:Game_Master:_Composition_Configuration_Tutorial

In the tools directory, there is a python script that convert a compo prefab to Json format used by darc missions mod (https://github.com/mokdevel/DarcMods/tree/main/DarcMissions/docs)
