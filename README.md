## _Media
Source images (loading screens, thumbnails, Workshop pages, custom textures), kept outside the addons and stored with Git LFS. See [_Media/README.md](_Media/README.md) (French).

## GDC_AR_Misc
Various mods, notably GDC AR Lib

- [GDC Loadout Editor](GDC_AR_Misc/GDC_AR_Lib/docs/GDC_LoadoutEditor.md): World Editor tool to edit the loadout of player character prefabs (French)
- [GDC AR Loadouts](GDC_AR_Misc/GDC_AR_Loadouts): player roles per faction (currently RHS USMC), added to the vanilla `LoadoutManager_Editor.et` used by COE2 and Game Master worlds

## GDC_AR_Missions
Contains various missions (e.g. Zimnitrita MCM Custom) and auto-generated missions (e.g. Zimnitrita Modern Combat Missions)

## GDC_AR_ModPack
Official mods for the community
